## 1.0.0 · 正式版

第一个正式版。开发期的 1.1.0 → 2.4.0 全部并入这里，功能齐了。

**她终于能自己出门了，也终于有刹车。**

- **能自己想起来**（第 3 期）：允许时段内（默认 `12:00-14:00,18:00-23:00`）插件每 60 秒看一眼——
  没在外面、没有待回申请、今天没叫够、冷却过了，就往群里塞一句「这会儿没人叫你」，
  让她自己决定要不要出去。默认**关**，要开得自己开。
- **出门要打招呼**（第 2 期）：`ask_permission` 申请 → 你在群里回「去吧」→ 限时通行证 →
  到点自动失效并汇报。只认发起会话 + 发起人（或全局管理员），申请 15 分钟没回作废。
- **替她说一句**（第 4 期）：DSH 在回复里写 `[[speak]]这句话[[/speak]]`，
  插件逐条查红线（钱/账号/验证码）和 @所有人、字数、每日额度，通过了才代发。
  DSH 本身没有发送权。
- **能翻页点开**（第 1 期缺口）：`page_act` 支持 read / click / type / scroll / press / back，
  一次最多 6 步；另有两条写死的红线（配置改不了）拦「购买 / 付款 / 改密码」和「发评论 / 发私信 / @所有人」。
- **持久 profile**：登录一次，之后 `look_around` 走出去都带着登录态。
- **九个平台扫码登录**：弹一个真浏览器，你在里面登录，成功自动存 Cookie。
  判断依据是 Cookie 里的登录标志键，不看页面长什么样。
- **全局管理员 QQ**：逗号分隔多个，批准出门这类事只认这些人；留空就是谁申请等谁回。
- **多值输入**：管理员 QQ 和「在哪个群里叫她」在设置页是一格一个、点 + 加一行。

## 2.4.0

  登录成功后自动把 Cookie 写进 `logins.json`。不用再去 F12 里翻 Cookie 复制粘贴。

  - 每次只开一个窗口，避免几个平台同时登把 profile 写坏。

  - B站 仍然额外写一份给「刷B站」插件读字幕用的 `bili_credential.json`。

  - `dsh_task` 的返回值会多一句说明：「DSH 借你的嘴说了 N 句」或「有 N 句没发：原因」。

  - 她正出门时会先等回来汇报，不会叠着再叫。
  - `outing_status` 会多报一句：现在认谁、自动模式开没开、今天叫过几次。

## 2.0.0

第 2 期：**出门要打招呼**。她能自己想去看看了，但得先问一声。

- **申请 → 批准 → 限时 → 回来汇报**，一条完整的链：
  1. 她调 `ask_permission`，插件替她发一条申请：「主人，我想出去转一会儿——想看看B站上那个新出的游戏。大概 30 分钟，可以吗？」
  2. **主人回一句「去吧」就算批了**（不用斜杠命令）。回「不行」就作废。
  3. 批了之后有一段时间的通行证，到期自动失效，**不用她记时间**。
  4. 到点时她要说一句「我回来啦」，顺带说看到了什么；提前回来可以调 `end_outing`。
- **只认该认的人**：申请发在哪个会话，就只等那个会话里的人回。别人说「去吧」不算数。
  - 想收得更紧就填 `[outing] owner_ids`（QQ 号），那样只有名单上的人能批。
- **有额度和时限**：每天最多出去几次（默认 3）、一次最多多久（默认 120 分钟）由配置管着；
  申请 15 分钟没人回就当没问过，不会一直挂着。
- **新增三个工具**：`ask_permission`（申请）、`end_outing`（提前回来）、`outing_status`（今天出去了几次、还剩多久）。
- **新增 EventHandler**：`outing_reply` —— 监听消息，认出「去吧 / 不行」这类回复，不用再敲命令。

## 1.9.0

补齐「出去看看」的三个缺口：**登录态、动手、白名单**。

- **持久 profile**：`look_around` 不再每次开一张白纸，改用 `browser-profile/`，
  和扫码登录共用同一份 cookie。打开 B站 就是她自己的登录态——首页推荐、观看历史、关注列表都是登录后那份。
  - 配置 `[browse] use_profile` / `profile_dir`；关掉就退回匿名上下文（每次重新注入 cookie）。
- **新增 `page_act` 工具**：能真正在页面上动手，不再只能看第一页。
  - 动作：`click`（选择器或文本）、`type`（填字，可带回车）、`scroll`（按 px 或到底/回顶）、`press`（按键）、`back`（后退）、`read`（记下当前页）。
  - 一次最多几步，每步之后等一会儿；任何一步失败就停，不会继续瞎点。
  - 翻页示例：`[{"op":"click","selector":"a[rel=next]"},{"op":"read"}]`。
- **动作白名单 + 红线**：`[actions] allowed` 控制她能做哪几种动作（默认六种全开，删几个就收紧）。
  - 写死的红线：**钱和账号**（付款 / 下单 / 充值 / 转账 / 改密码 / 注销 / 解绑 / 实名）一律拒绝。
  - 往外面说话（评论 / 弹幕 / 私信 / 投稿 / 转发）也一律拒绝——那是第 4 期「代发」的事，得先过主人。
  - 拒绝时会说清楚是第几步、碰了哪个词，不会含糊过去。
